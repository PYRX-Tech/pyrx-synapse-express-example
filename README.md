# Synapse Express Example

Example showing how to use [@pyrx/synapse](https://www.npmjs.com/package/@pyrx/synapse) with Express.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env` and fill in your API key
3. `npm run dev`

## Endpoints

- `POST /api/track` — Track an event
- `POST /api/identify` — Identify a contact
- `POST /api/send` — Send a transactional email
